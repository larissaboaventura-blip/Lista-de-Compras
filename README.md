# 🛒 Lista de Compras

## Sobre o projeto

A **Lista de Compras** é um aplicativo desenvolvido com React Native e Expo, utilizando TypeScript. O objetivo é facilitar a organização das compras, permitindo visualizar produtos e suas respectivas quantidades em uma lista simples e prática.

## Tecnologias utilizadas

* **React Native:** criação da interface do aplicativo.
* **Expo:** ferramenta para facilitar o desenvolvimento e a execução do projeto.
* **TypeScript:** adiciona tipagem ao JavaScript, ajudando a evitar erros no código.
* **React:** gerenciamento de componentes e estados da aplicação.
* **Node.js e npm:** ambiente e gerenciamento de pacotes necessários para o desenvolvimento.

## Funcionalidades

* Exibição de uma lista de compras.
* Visualização dos nomes dos produtos.
* Controle das quantidades dos itens.
* Organização da interface por meio de componentes.
* Gerenciamento dos itens utilizando o estado do React.

## Objetivo

O projeto tem como objetivo aplicar conhecimentos de desenvolvimento de aplicativos móveis, utilizando componentes reutilizáveis, gerenciamento de estados e tipagem com TypeScript.

## Desenvolvimento

Projeto desenvolvido para fins de aprendizagem e prática de programação com React Native, Expo e TypeScript.
